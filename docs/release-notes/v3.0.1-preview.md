Fixes found by building a demo mode and looking at the app with no game
attached, which turned out to be the only way to see several of these.

- **Light mode:** the alert banners drew as solid blocks with their own
  labels invisible. Darkening a colour was dropping the transparency it
  already carried.
- The win-probability bar and the alert banners stayed on screen on the
  history and encounters views, where they described nothing.
- Returning to the lobby left the previous view's text in the status line.
- The window capped its own height at 880px regardless of the screen, so a
  full lobby with both alerts up scrolled when there was room for it.
- The preview and crash logs ignored the data folder setting.

**Still a preview**, and unchanged in what it does: read-only, local APIs
only, nothing uploaded.
